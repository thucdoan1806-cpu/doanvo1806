# Personal Website

A simple personal website created to introduce myself and present my work, interests, and background.

## Built With

* HTML
* CSS

## About

This project focuses on the visual structure, layout, typography, and overall presentation of a personal website. It was built from scratch as a coding learning project.

The current version is mainly basic front-end and does not yet include JavaScript or more advanced functionality.

## Status

🚧 In progress — the website is still a basic version and can be further developed with JavaScript, additional content, improved responsiveness, and interactive features.

## Purpose

This project helped me gain hands-on experience with HTML/CSS and explore how design concepts can be translated into a functional web interface.
